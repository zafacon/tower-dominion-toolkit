# Tower Dominion Toolkit v0.4.0-pre.2

## Gameplay fixes and Abundant Tiles — pre-release

- Adds Abundant Tiles: every round receives one tile-placement opportunity, while an actual nest remains the single placement for its round.
- Fixes Armored Staging Ground Auctoritas HP upgrades so the native +1250/+2500 HP effects can apply to HQ-spawned tanks.
- Fixes the HQ repair tooltip so external per-battlefront doctrine repair contributions are included in the displayed repair percentage and HP-per-wave.
- Retains the corrective RNG, stable neutral placement/preview, Discovery rules, Bryta Nest Reroll, Rear Guard Longest Path, and No Duplicate Rewards from pre.1.
- Packaging now includes the corrective RNG dependency and supports prerelease semantic versions.

Automated suite: 504 tests passed. Abundant Tiles and both gameplay/UI fixes were live-validated before publication.

This remains a pre-release intended for broader player testing, not the stable release.

Install the ZIP with the game closed and replace all Toolkit DLLs together. Requires MelonLoader. Include MelonLoader/Latest.log when reporting issues.
